# 🎓 DCode Student Developer Club - Official Website

The official website of DCode Student Developer Club at SSIEMS, Parbhani.

**🌐 Live Site:** [https://www.dcode.club](https://www.dcode.club)

---

## 🚀 About

This website showcases club activities, achievements, upcoming events, and provides information for students interested in joining our developer community at Shri Shivaji Institute of Engineering and Management Studies (SSIEMS), Parbhani.

---

## ✨ Features

- Modern, responsive design
- Event showcase and gallery
- Team and partner sections
- Easy registration process
- Mobile-friendly layout
- Dark theme optimized

---

## 🛠️ Tech Stack

- **Frontend:** React 18 + TypeScript
- **Styling:** Tailwind CSS
- **Build Tool:** Vite
- **UI Components:** Radix UI
- **Icons:** Lucide React

---

## 🚀 Getting Started

### Prerequisites

- Node.js v18 or higher
- npm v9 or higher
- Git

### Installation

**1. Clone the repository**
```bash
git clone https://github.com/SyedAsif7/DDSC-main.git
cd DDSC-main
```

**2. Install dependencies**
```bash
npm install
```

**3. Start development server**
```bash
npm run dev
```

The app will open at [http://localhost:5173](http://localhost:5173)

## 🚀 Deployment

### Deploy to Vercel
```bash
npm install -g vercel
vercel deploy --prod
```

### Deploy to Netlify
```bash
npm install -g netlify-cli
netlify deploy --prod --dir=dist
```

Or simply upload the contents of the `dist/` folder to any static hosting provider.
